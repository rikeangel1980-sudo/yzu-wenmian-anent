# P05 三套视觉方案 · 设计定调说明（frontend-design 重构版）

> 依据：user 反馈"只是三种颜色搭配，不是三种视觉风格；需要排版布局也不同；当前比较死板"。
> 方法论：`frontend-design` skill（中文版 references/zh-CN.md）。
> 日期：2026-11-24

## 共同目的与约束

- **目的**：面向《面点工艺学》教学的 AI 平台，给教师/学生两套分离的工作空间。
- **约束**：单文件可运行原型、light 主题为主（IDE 为 light）、原生 HTML/CSS/JS、可访问性 ≥4.5:1、动效可降级。
- **硬红线**（来自 PRD）：学生首页不得混入调试/账号技术信息；师生导航分离；异常态必须有登录/重试/返回入口，不裸出 `AUTH_REQUIRED`。

## 三套方案的"方向锁定"（每个只选一个方向，不混搭）

### 方案 A —— Editorial / 杂志编辑风（教材质感的"教学杂志"）
- **受众**：学生端为主，强调内容阅读与教材权威感。
- **调性**：杂志编辑（Editorial），不是卡片仪表盘。
- **排版**：多栏网格 + 规则线 + 首字下沉 + 引言块 + 大字号章节号；非对称双栏（正文宽栏 + 侧栏注释）；顶部是细线眉题而非搜索框。
- **字体**：展示字 `Playfair Display` / 中文 `Noto Serif SC`（思源宋体）；正文 `Noto Serif SC`，行高 1.8，字距 .02em。
- **配色**：暖纸白 `#f6f2ea` 底 + 墨黑 `#24201c` 字 + 朱砂红 `#b23a2b` 单一强调色；60/30/10。
- **氛围**：纸张颗粒噪点 + 发丝分隔线 + 垂直装饰细线 + 章节大数字压边。
- **记忆点**：首字下沉的正文与朱砂色章节编号，像翻开一本面点专著。
- **导航**：左边缘竖向细排章节（如书脊目录），不是常规侧栏按钮列表。

### 方案 B —— Industrial / 工业实用风（B 端教学控制台）
- **受众**：教师端为主，高密度备课/审核/批改。
- **调性**：工业实用（Industrial），不是圆角卡片 SaaS。
- **排版**：仪表盘密信息网格 + 等宽数字 `tabular-nums` + 发丝边框 + 数据条；左窄工具栏 + 顶部状态条；卡片是硬朗方角、细边框、分区清晰。
- **字体**：展示字 `Archivo Black`；正文 `IBM Plex Sans`；数字 `IBM Plex Mono`。
- **配色**：冷灰白 `#eef1f3` 底 + 深钢蓝 `#16324f` + 信号橙 `#ff6b2c` 强调；60/30/10。
- **氛围**：网格底纹 + 状态色体系（已审核/待审/失败）+ 发丝线 + 数据条带；去阴影，靠边框分层。
- **记忆点**：等宽数字指标墙 + 信号橙的关键动作按钮，像一台可靠的控制台。
- **导航**：左侧图标工具栏（窄）+ 顶部 breadcrumb 状态条。

### 方案 C —— Organic / 自然有机风（面点手艺人的温暖工作台）
- **受众**：学生端亲和场景，突出"手艺/食物"温度。
- **调性**：自然有机（Organic），不是玩具卡通风。
- **排版**：柔和曲线分区 + 大圆角但不统一 + 错落重叠卡片 + 手绘感装饰；非对称错落布局，卡片有轻微旋转/位移；大量留白。
- **字体**：展示字 `Fraunces`（衬线有温度）；正文 `Karla` / 中文 `Noto Sans SC`。
- **配色**：奶油 `#faf4e8` 底 + 深可可 `#3d2c20` 字 + 麦穗金 `#c8892f` 与苔绿 `#5a7247` 双辅助，强调色单个用麦穗金；60/30/10。
- **氛围**：柔和径向渐变网格 + 噪点 + 有机形状（border-radius 非对称如 `60% 40% 55% 45%`）+ 层叠透明面板。
- **记忆点**：像揉面般柔和的不规则色块与错落卡片，温暖不幼稚。
- **导航**：顶部悬浮胶囊导航 + 大留白内容区。

## 与旧版的关键差异

| 维度 | 旧版（被否） | 新版 |
|---|---|---|
| 差异层级 | 只换主色 + 侧栏/顶栏位置 | 排版系统、字体、栅格、装饰语言全不同 |
| 字体 | 全方案 system-ui | 三套各自展示字+正文字，均非禁用字体 |
| 布局骨架 | 统一"侧栏+统计卡+列表卡" | 杂志多栏 / 工业仪表盘 / 有机错落 |
| 氛围 | 纯色平铺 + 统一阴影 | 颗粒 / 网格底纹 / 有机渐变各不同 |
| 卡片 | 一模一样圆角卡 | 按方向分别用 规则线分区 / 方角细边 / 不规则圆角 |

## 反 AI 味自检承诺

交付前逐项核对 skill 的 12 条检查表：展示字非禁用、非白底紫渐变、首屏非"居中标题+两按钮+三卡"、卡片不统一、图标有信息含义、文案无空话、动效编排错峰、有氛围层、有记忆点、状态覆盖、可访问性。命中项全部修复后再交付。
