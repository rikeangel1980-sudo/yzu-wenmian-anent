## 2. 三套视觉方案（结构级差异）

### A · 杂志编辑风（Editorial）—— 教材质感的"教学杂志"
- **排版**：竖排"目次"书脊导航 + 顶眉刊头；正文非对称双栏（宽栏正文 + 边栏待办）；规则线分隔；**首字下沉**与**朱砂章节大数字（03 / 12）**。
- **字体**：Playfair Display / 思源宋体（Noto Serif SC）；正文宋体行高 1.85。
- **配色**：暖纸白 `#f6f2ea` + 墨黑 `#24201c` + 朱砂 `#b23a2b` 单一强调。
- **记忆点**：像翻开一本面点专著——"水"字首字下沉 + 教材摘录引用块。
- **适配**：学生端为主，强调阅读与教材权威感。

### B · 工业实用风（Industrial）—— B 端教学控制台
- **排版**：深钢蓝状态条（SYS ONLINE / DB / HOST）+ 窄图标工具栏 + **等宽数字指标墙** + 方角发丝边框面板 + 状态徽章体系。
- **字体**：Archivo Black / IBM Plex Sans / IBM Plex Mono（数字 tabular-nums）。
- **配色**：冷灰白 `#eef1f3` + 深钢蓝 `#16324f` + 信号橙 `#ff6b2c`。
- **记忆点**：等宽数字指标墙 12/8/3/5 + 状态面板，像一台可靠的教学控制台。
- **适配**：教师端为主，高密度备课/审核/批改。

### C · 自然有机风（Organic）—— 面点手艺人的温暖工作台
- **排版**：悬浮胶囊导航 + 有机渐变色块 hero + **不规则圆角且错落位移**的卡片 + 大留白。
- **字体**：Fraunces / Karla / 思源黑体。
- **配色**：奶油 `#faf4e8` + 深可可 `#3d2c20` + 麦穗金 `#c8892f` + 苔绿辅助。
- **记忆点**：像揉面般柔和的不规则色块与错落卡片，温暖而不幼稚。
- **适配**：学生端亲和场景，突出"手艺/食物"温度。

> 三套均保持 light 主题（内容区浅色、文字深色）；仅 A 的书脊与 B 的顶栏为深色导航区。

## 3. 原型覆盖清单

| 维度 | 覆盖 |
|---|---|
| 角色 | 学生端 / 教师端，导航体系分离（7 项 / 10 项） |
| 学生页面 | 首页、课程、知识详情、图谱（三栏）、视频、测评、任务 |
| 教师页面 | 首页、班级、知识、图谱、题库、AI 出题、组卷、批改、学情、视频 |
| 核心交互 | 登录/退出、导航跳转、待办直达、题目审核、AI 生成候选、组卷加题与分值联动、批改 AI 建议可改与终评分联动、图谱节点选中 |
| 异常态 | 会话失效（重新登录+返回）、加载失败（NET-503+重试）、加载中（骨架屏）、未授权 |
| 数据口径 | 全部《面点工艺学》语境模拟数据，标注"实时"口径，不混入旧快照 |

Hash 直达：`#scheme=A|B|C&role=student|teacher&page=<页>&logged=1&state=<异常态>`。
