### 1.2 P07 不做什么

## 2. 总体约定（全模块共享）

### 2.1 数据库与 ER 通用约定

| 项 | 约定 |
|---|---|
| 引擎 | SQLite 3.45.3+，WAL，`busy_timeout=5000`，`foreign_keys=ON`，本机非同步目录（ADR-003） |
| 访问 | 标准库 `sqlite3` + `schema_migrations` 版本表；Repository 只暴露 `get/list/save/delete/transaction`，不返回裸 cursor（ADR-004） |
| 迁移文件 | `migrations/0001_xxx.sql` 编号升序，含 `up/down`、文件 SHA-256、执行前后版本与审计；启动检查执行，禁止无迁移直改 Schema |
| 主键 | 全部业务主键为 `TEXT` 类型 UUID（小写下划线命名如 `acc_xxx` 仅作人类可读前缀，**ID 本身是 UUID**）；禁止自增 ID 出现在 URL、审计与跨模块外键 |
| 身份 ID | 内部 `account_id` 为 UUID；`student_no` 仅作登录名与名单映射，**不得作为外键、URL 参数、日志与导出默认字段**（C-06 / ADR-008） |
| 时间 | 所有时间列 `TEXT`，ISO 8601 UTC（`2026-11-24T14:00:00Z`）；展示层按本机时区格式化 |
| 布尔 | `INTEGER NOT NULL DEFAULT 0` / `1`；不存字符串布尔 |
| 枚举 | `TEXT` + `CHECK` 约束；应用层用 `Enum` 校验，DB 约束兜底 |
| 软删除 | 业务对象用 `status='archived'` / `deleted_at`；审计链与成绩链不物理删除（ADR-012 / OPEN-11） |
| 并发 | 写事务短小；列表分页 `LIMIT/OFFSET` + 稳定排序键；并发更新带 `version` 乐观锁，冲突返回 `VALID_VERSION_CONFLICT` |
| 索引 | 外键列、状态列、时间列建索引；全文检索不在 SQLite FTS 做中文，走 MOD-KNOW 自有索引 |

**通用 ER 主干**（各模块在自身小节扩展）：

```
accounts (1) ──< class_memberships >── (1) classes (N) ──> (1) courses
    │                                        │
    │                                        └──> textbooks (MOD-KNOW, 版本快照)
    └──< sessions / audit_logs / submissions / exam_attempts
courses (1) ──< knowledge_units >── (1) evidence (MOD-KNOW)
                    │
                    └──< graph_nodes / questions / video_links (MOD-KG/QEX/VID)
```

**跨模块外键规则**：只在外键列保存 UUID，不复制业务名称；跨模块读通过 Repository 接口，不直连他模块表。教材版本属于 MOD-KNOW，`courses.textbook_version_id` 可为空，未发布版本不得被课程引用。

### 2.2 API 契约通用约定（Pydantic / OpenAPI）

| 项 | 约定 |
|---|---|
| 前缀 | `/api/v2/*`，与契约文件版本绑定；破坏性变更升版本并保留兼容窗口（ADR-014） |
| 契约源 | Pydantic v2 Schema 为唯一契约源；P10 导出 `openapi.json` 入 Git；P08 以导出文件做契约核对 |
| 成功响应 | `{ "data": ..., "meta": { "request_id", "timestamp", "version" } }` |
| 错误响应 | `{ "error": { "code", "message", "details", "request_id" } }` |
| 错误码族 | `AUTH_*`、`PERM_*`、`VALID_*`、`AI_DEGRADED`、`TASK_*`、`UPLOAD_*`、`NET_*`（ADR-014） |
| 鉴权依赖 | 所有非公开端点声明 `Depends(require_scope(...))`；`must_change_password` 用户走独立依赖 `require_full_auth` |
| 幂等 | 写操作可带 `Idempotency-Key`；重复提交返回首次结果，不重复计分/建单 |
| 状态字段 | 响应中的 `status` 一律返回枚举值（英文），展示文案由前端映射，不做服务端本地化字符串 |
| 分页 | `?page=1&page_size=20`，响应 `meta` 含 `total`；上限可配置，不写死 |
| 文件上传 | multipart；服务端校验扩展名 + MIME + 文件签名 + 大小，随机文件名，鉴权下载（ADR-009） |
| 审计 | 每个写请求在 Application Service 层写 `audit_logs`，含 `request_id` 与操作者 UUID |

**核心错误码表（P07 定义，P08 逐项测试）**：

| Code | HTTP | 场景 |
|---|---|---|
| `AUTH_INVALID_CREDENTIALS` | 401 | 账号不存在/密码错误/已禁用（**同一文案**） |
| `AUTH_ACCOUNT_LOCKED` | 423 | 连续失败达阈值，含解锁时间 |
| `AUTH_SESSION_EXPIRED` | 401 | 会话失效，前端渲染登录恢复页 |
| `PERM_FORBIDDEN` | 403 | 角色/范围越权 |
| `PERM_PASSWORD_CHANGE_REQUIRED` | 403 | `must_change_password=1` 访问非白名单端点 |
| `VALID_VERSION_CONFLICT` | 409 | 乐观锁冲突 |
| `VALID_OUT_OF_SCOPE_CITATION` | 422 | 引用越界或不存在，服务端拦截 |
| `AI_DEGRADED` | 200 / 503 | 无 Key 降级可用 / 不可用（依端点定义） |
| `TASK_TIMEOUT` | 504 | 异步任务超时 |
| `UPLOAD_INVALID_TYPE` | 415 | 文件类型/签名校验失败 |

### 2.4 状态机通用规则

- 迁移只能在 Application Service 中执行；Domain Service 提供 `can_transition(from, to)`，非法迁移抛 `VALID_ILLEGAL_TRANSITION` 并写审计。
- 每次迁移写 `state_events`（`object_type/object_id/from/to/actor_id/reason/created_at`），供学情与运维查询。
- 长任务必须有 `queued/running/succeeded/failed/degraded` 与超时、重试上限；相同请求幂等。
- 发布类状态（`published`）必须满足前置校验（总分/题状态/对象/时间/证据），否则拒绝迁移。

### 2.5 安全与日志通用约定

| 项 | 约定 |
|---|---|
| 密码 | 专用哈希（argon2id 优先，bcrypt 备选，参数配置化）；禁止 SHA/MD5；初始密码单用户随机生成 |
| 会话 | Cookie `httpOnly` + `SameSite=Lax` + `Secure` 仅 HTTPS 时启用；有效期配置化；退出即撤销 |
| CSRF | 所有写方法校验 `X-CSRF-Token`；loopback 亦启用 |
| 限流 | 登录失败按账号 + IP 双维度计数，阈值/窗口配置化 |
| 脱敏 | 日志不出现密码、Key、令牌、`student_no`；用 `account_id` 与 `request_id` 追溯 |
| 出域 | 模型调用前经过出域闸门；学生材料逐次 D3 批准；姓名/学号/班级/成绩默认不出域（ADR-007） |
| 审计最小字段 | `actor_id`、`actor_role`、`action`、`object_type`、`object_id`、`result`、`details_json`、`request_id`、`created_at`（FND-008） |
| 导出 | 默认不含学号/姓名；授权导出写独立审计记录；导出与页面筛选同源 |
| Key | 仅存本机受保护配置文件/环境变量，不进前端、Git、日志、导出包 |

## 3. MOD-BASE｜平台基础与课程班级（第一个开发模块）

**需求映射**：FND-001~010（10 项 MUST）；对应 `ADR-001/003/004/008/014`、`P06 §3.4`、`P06 §6 登录/权限数据流`。

### 3.1 数据库表与 ER

```sql
-- 账号：学号仅登录/名单映射；内部 UUID 为唯一身份
CREATE TABLE accounts (
  account_id            TEXT PRIMARY KEY,
  student_no            TEXT UNIQUE,                 -- 教师/管理员为 NULL；导入学生必填
  display_name          TEXT NOT NULL,
  role                  TEXT NOT NULL CHECK (role IN ('admin','teacher','student','reviewer')),
  account_source        TEXT NOT NULL CHECK (account_source IN ('admin_created','roster_import')),
  password_hash         TEXT NOT NULL,
  password_algo         TEXT NOT NULL DEFAULT 'argon2id',
  must_change_password  INTEGER NOT NULL DEFAULT 0 CHECK (must_change_password IN (0,1)),
  status                TEXT NOT NULL DEFAULT 'active'
                        CHECK (status IN ('active','disabled','locked')),
  failed_attempts       INTEGER NOT NULL DEFAULT 0,
  locked_until          TEXT,
  last_login_at         TEXT,
  created_by            TEXT,
  created_at            TEXT NOT NULL,
  updated_at            TEXT NOT NULL,
  version               INTEGER NOT NULL DEFAULT 1
);
CREATE INDEX idx_accounts_role_status ON accounts(role, status);

-- 课程：显示名独立于教材名（PRD-CR-004）
CREATE TABLE courses (
  course_id            TEXT PRIMARY KEY,
  display_name         TEXT NOT NULL DEFAULT '待配置',
  description          TEXT NOT NULL DEFAULT '',
  semester             TEXT,
  textbook_version_id  TEXT,                         -- MOD-KNOW 版本 UUID，未发布时为空
  owner_account_id     TEXT NOT NULL REFERENCES accounts(account_id),
  status               TEXT NOT NULL DEFAULT 'draft'
                       CHECK (status IN ('draft','active','archived')),
  created_at           TEXT NOT NULL,
  updated_at           TEXT NOT NULL,
  version              INTEGER NOT NULL DEFAULT 1
);

-- 教学班
CREATE TABLE classes (
  class_id     TEXT PRIMARY KEY,
  course_id    TEXT NOT NULL REFERENCES courses(course_id),
  name         TEXT NOT NULL,
  semester     TEXT,
  status       TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active','archived')),
  created_at   TEXT NOT NULL,
  updated_at   TEXT NOT NULL,
  version      INTEGER NOT NULL DEFAULT 1

CREATE INDEX idx_classes_course ON classes(course_id, status);

-- 成员关系：教师账号只能由管理员创建，不得由名单导入产生
CREATE TABLE class_memberships (
  membership_id TEXT PRIMARY KEY,
  class_id      TEXT NOT NULL REFERENCES classes(class_id),
  account_id    TEXT NOT NULL REFERENCES accounts(account_id),
  role_in_class TEXT NOT NULL CHECK (role_in_class IN ('teacher','student','reviewer')),
  status        TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active','removed')),
  created_by    TEXT NOT NULL REFERENCES accounts(account_id),

-- 会话：token 与 CSRF token 都只存哈希（独立审查 F-02）
CREATE TABLE sessions (
  session_id     TEXT PRIMARY KEY,                   -- token SHA-256
  account_id     TEXT NOT NULL REFERENCES accounts(account_id),

  created_at     TEXT NOT NULL,
  expires_at     TEXT NOT NULL,
  last_seen_at   TEXT NOT NULL,
  status         TEXT NOT NULL DEFAULT 'active'
                 CHECK (status IN ('active','revoked','expired')),
  revoked_at     TEXT
);
CREATE INDEX idx_sessions_account ON sessions(account_id, status);

-- 登录失败计数（账号+IP 双维度）；不存明文学号（独立审查 F-01）
CREATE TABLE login_attempts (
  attempt_id   TEXT PRIMARY KEY,
  student_no_hash TEXT NOT NULL,                    -- 学号 SHA-256；不参与外键/日志/导出
  ip_hash      TEXT NOT NULL,
  succeeded    INTEGER NOT NULL DEFAULT 0,
  created_at   TEXT NOT NULL
);

-- 名单导入任务与错误行
CREATE TABLE import_jobs (
  job_id        TEXT PRIMARY KEY,
  class_id      TEXT NOT NULL REFERENCES classes(class_id),
  operator_id   TEXT NOT NULL REFERENCES accounts(account_id),
  filename      TEXT NOT NULL,
  file_sha256   TEXT NOT NULL,
  status        TEXT NOT NULL CHECK (status IN
                ('previewing','importing','partial_success','success','failed')),
  mapping_json  TEXT NOT NULL DEFAULT '{}',
  preview_json  TEXT NOT NULL DEFAULT '[]',
  total_rows    INTEGER NOT NULL DEFAULT 0,
  success_rows  INTEGER NOT NULL DEFAULT 0,
  error_rows    INTEGER NOT NULL DEFAULT 0,
  error_file    TEXT,
  created_at    TEXT NOT NULL,
  finished_at   TEXT
);

CREATE TABLE import_errors (
  error_id   TEXT PRIMARY KEY,
  job_id     TEXT NOT NULL REFERENCES import_jobs(job_id),
  row_no     INTEGER NOT NULL,
  reason     TEXT NOT NULL,
  raw_json   TEXT NOT NULL
);
CREATE INDEX idx_import_errors_job ON import_errors(job_id, row_no);

-- 审计与状态事件（只追加）
CREATE TABLE audit_logs (
  audit_id      TEXT PRIMARY KEY,
  actor_id      TEXT REFERENCES accounts(account_id),
  actor_role    TEXT,
  action        TEXT NOT NULL,
  object_type   TEXT NOT NULL,
  object_id     TEXT,
  result        TEXT NOT NULL CHECK (result IN ('success','denied','failure')),
  details_json  TEXT NOT NULL DEFAULT '{}',
  ip_hash       TEXT,
  request_id    TEXT NOT NULL,
  created_at    TEXT NOT NULL
);
CREATE INDEX idx_audit_actor_time ON audit_logs(actor_id, created_at);
CREATE INDEX idx_audit_object ON audit_logs(object_type, object_id);

CREATE TABLE state_events (
  event_id     TEXT PRIMARY KEY,
  object_type  TEXT NOT NULL,
  object_id    TEXT NOT NULL,
  from_state   TEXT,
  to_state     TEXT NOT NULL,
  actor_id     TEXT NOT NULL REFERENCES accounts(account_id),
  reason       TEXT NOT NULL DEFAULT '',
  request_id   TEXT NOT NULL,
  created_at   TEXT NOT NULL
);
CREATE INDEX idx_state_events_object ON state_events(object_type, object_id, created_at);

-- 备份清单
CREATE TABLE backups (
  backup_id     TEXT PRIMARY KEY,
  kind          TEXT NOT NULL CHECK (kind IN ('manual','scheduled','pre_restore')),
  manifest_path TEXT NOT NULL,
  db_sha256     TEXT NOT NULL,
  files_json    TEXT NOT NULL DEFAULT '[]',
  size_bytes    INTEGER NOT NULL DEFAULT 0,
  status        TEXT NOT NULL DEFAULT 'creating'

  created_by    TEXT NOT NULL REFERENCES accounts(account_id),
  created_at    TEXT NOT NULL,
  verified_at   TEXT
```

**ER 要点**：

- `accounts` 1—N `class_memberships` N—1 `classes` N—1 `courses`；教师/学生通过成员关系获得课程班级范围，不直接挂课程。
- `accounts` 1—N `sessions` / `audit_logs` / `state_events` / `import_jobs`；审计与事件只追加，不随账号归档删除。
- `import_jobs` 1—N `import_errors`；错误行与导入任务同生命周期，错误 CSV 由二者派生。
- `courses.textbook_version_id` 引用 MOD-KNOW 的 `textbook_versions`，**仅允许引用 `status='published'` 的版本**，发布/切换属 D3。

### 3.2 状态机

| 对象 | 状态/维度 | 合法迁移与约束 |
|---|---|---|
| 账号状态 | `active → disabled → active`；`active → locked → active` | 锁定由失败阈值触发，解锁由时间窗口或管理员；`disabled` 不自动解锁 |
| 强制改密 | `must_change_password ∈ {0,1}` | 导入创建时置 1；成功改密置 0 且初始密码立即失效；**这是独立于 status 的授权维度，不是 UI 提示** |
| 会话 | `active → revoked / expired` | 退出、改密、管理员禁用账号均撤销全部会话；过期会话不可续期 |
| 课程 | `draft → active → archived` | 教材版本未发布不允许 `active`；归档不删除班级与历史数据 |
| 班级 | `active → archived → active` | 归档后学生端不可见，历史成绩保留 |
| 名单导入 | `previewing → importing → success / partial_success / failed` | 部分成功：合法行入库、错误行跳过；重复学号不覆盖；错误行可下载 CSV |

**非法迁移**：服务端拒绝并写 `audit_logs(result='denied')` 与 `state_events`；前端不得自行推导状态跳转。

### 3.5 安全与日志

**登录与限速**：

1. 账号不存在时也执行一次哑哈希校验，使响应时间与密码错误接近；两者返回同一 `AUTH_INVALID_CREDENTIALS`。
2. 按学号哈希 + IP 哈希双维度计数；达阈值置 `status='locked'` 与 `locked_until`；锁定期内正确密码同样拒绝（`AUTH_ACCOUNT_LOCKED`）。
3. 成功登录：`failed_attempts=0`，新建 `sessions`，写审计；`student_no` 不写入任何日志与前端响应之外的位置。
4. 退出/改密/管理员禁用：撤销该账号全部 `active` 会话。

**`must_change_password` 服务端拦截（核心）**：

```python
PUBLIC_PATHS = {'/api/v2/auth/login'}
PRE_CHANGE_PATHS = {
    '/api/v2/auth/change-password', '/api/v2/auth/logout', '/api/v2/auth/me'
}

def require_full_auth(request: Request, sess=Depends(get_session)) -> Account:
    if sess.status != 'active' or sess.expires_at <= now_utc():
        raise ApiError('AUTH_SESSION_EXPIRED', 401)
    acc = repo.accounts.get(sess.account_id)
    if acc.status != 'active':
        raise ApiError('AUTH_INVALID_CREDENTIALS', 401)
    if acc.must_change_password and request.url.path not in PRE_CHANGE_PATHS:
        raise ApiError('PERM_PASSWORD_CHANGE_REQUIRED', 403)
    return acc
```

> 前端隐藏按钮**不算**权限控制；所有非白名单端点必须声明该依赖。P08 以 8 入口一致性用例验证。

**名单导入规则**：

- 预览阶段只解析不入库；字段映射可人工修正；`student_no` 为空/重复/非法字符均列为错误行。
- 提交阶段逐行事务；重复学号返回错误行，**不静默覆盖**；合法行创建 `account_source='roster_import'`、`must_change_password=1`。
- 错误 CSV 列：`row_no, reason, raw_json`；不导出密码与初始密码。
- 教师账号不在名单导入允许角色内，防止 `roster_import` 产生教师。

**备份与恢复**：

- 备份用 SQLite 一致性备份 API，清单含 DB 与各资源文件 SHA-256、相对路径、大小；manifest 自身入 Git 忽略列表。
- 恢复前校验：清单文件齐全、哈希一致、目标目录为空或已确认；恢复后逐表比对记录数与关键字段，抽查试卷快照/提交版本/审核历史（P13 演练）。

### 4.1 检索策略决策：不集成 `kb-memory`

本轮实际查证 `https://pypi.org/project/kb-memory/` 及仓库 `README_EN.md`、`requirements.txt`（2026-11-24），结论：**不引入该包，不引入第二服务**，保持 `ADR-006` 的 jieba + BM25 基线，并按本节把检索能力工具化。

| 判据 | 查证事实 | 决策理由 |
|---|---|---|
| 检索路线 | `kb-memory` v2.5.0 为向量 + BM25 混合，依赖 `chromadb>=1.5,<2.0`、`sentence-transformers>=3.0,<7.0`、torch（Windows CPU 轮约 124 MB） | `ADR-006` 明确向量库暂缓，仅在 golden set 证明 BM25 稳定召回缺口后启动 PoC；当前无该证据 |
| 运行形态 | 独立常驻进程 `python -m kb serve`，`127.0.0.1:8000`，REST + MCP + Web UI + 独立数据目录 | 与 `ADR-001` 本机单实例 `127.0.0.1:8787` 及代码冻结/全量回归交付流程冲突 |
| 结构保留 | 文档只说明「chunk」，未提供章节/页码字段；重新入库替换旧 chunk；图谱明确「文档/网页/表格不进入图谱」 | 无法满足 `STU-006` 章节定位与 `ADR-012` 不可变快照；不能解决教材结构模糊 |
| 许可证 | Apache-2.0，工程化尚可（自述 544 项测试） | 许可证干净，但收益不抵依赖与治理成本；其工具划分/审计设计可作为接口参考 |

**借鉴而非引入**：单一职责工具划分、命名空间隔离、访问审计逐条落盘、确定性匹配优先于语义匹配。以上作为 `KBTool` 契约设计参考，不复制代码、不加依赖。

### 4.3 KBTool 工具化检索契约（P0 主链路）

**接口定义（Application Service 层，非 MCP、非独立进程）**：

```python
class KBTool:
    def search(self, query: str, scope: Scope,
               top_k: int, textbook_version: UUID) -> SearchResult: ...
    def get_evidence(self, evidence_id: UUID) -> EvidenceDetail: ...
    def neighbors(self, node_id: str, depth: int = 1) -> NeighborResult: ...
    def reindex(self, textbook_version: UUID) -> IndexResult: ...

class SearchResult(BaseModel):
    version_id: UUID
    hits: list[Hit]                 # evidence_id / locator / snippet / score
    evidence_ids: list[UUID]        # 只允许这些 ID 进入回答引用
    coverage: float                 # 0..1，由召回质量计算，非模型自评
    degraded: bool                  # 索引未就绪时为 True，走降级提示
```

**编排规则（L1 确定性，不可绕过）**：

1. 每个问答请求**必须**先调用 `KBTool.search` 一次；未调用直接生成视为违规，服务端拒绝。
2. 原问题先过域外词闸门；命中域外词直接出教学边界通知书，不进入检索与模型。
3. `judge_rejection(question, hits, coverage)` 是**唯一**拒答判据；所有问答入口共用，返回 `accept` / `boundary` / `insufficient`。
4. `boundary` → 教学边界通知书；`insufficient` → 最多 2 次**规则化查询改写**（课程词典同义词 + 章节上下文补全），每次改写后再过域词闸门并调用 `search`，全过程写 `kb_tool_calls.rewritten_from`。
5. 改写后仍 `insufficient` → 明确「教材证据不足」+ 教材章节定位建议 + 教师提问入口；**不进入通用生成、不联网**。
6. 引用由服务端按 `evidence_ids` 渲染；`_cite_overflow` 校验失败则剔除越界引用并重算覆盖率。

**Agent 策略（L2）**：仅预留 `KBTool` 契约与调用审计字段；P0 不启用「Agent 自主决定是否查库/联网」。登记 `ENH-009 Agentic 检索策略`（SHOULD，不占 P0 关键路径），须在 P08 有对应受控清单且 D3 授权后才可进入开发。

```sql
  requester_id TEXT NOT NULL REFERENCES accounts(account_id),

               CHECK (decision IN ('pending','approved','rejected')),
  reason       TEXT NOT NULL DEFAULT '',

);
```

**AI 任务状态机**：`queued → running → succeeded / failed / degraded`；无 Key 或模型不可用时置 `degraded` 并保留本地能力；超时置 `failed`；重试幂等且次数上限可配置。

### 4.5 ModelGateway 与不可信输出闸门

```
业务模块 → ModelGateway.text(task, payload) / .vision(task, payload)
         → ProviderAdapter（按 kind 与配置选择 text/vision）
         → 出域闸门（D3 批准检查 + 脱敏 + 最小片段）
         → 调用记录 ai_calls
         → 返回后处理：Schema 校验 → 引用校验 → 权限过滤 → 内容安全检查
         → ai_suggestions(draft) 或 回答渲染
```

- 业务模块**不得**直接 import 厂商 SDK；Provider 变更只改 Adapter 与配置（ADR-007）。
- 无 Key：`ModelGateway` 返回 `degraded`，问答走 extractive 原文直出并提示降级；出题/组卷/图谱浏览仍可用。
- 模型输出一律不可信：结构不合法即拒绝；引用不在 `evidence_ids` 内即剔除；越权对象不返回。
- 预算：`ai_providers.monthly_budget` 为硬上限，达上限自动切 degraded 并告警；数值由 D3 配置，不在代码中写死。

```sql
  account_id    TEXT NOT NULL REFERENCES accounts(account_id),
  valid_ms      INTEGER NOT NULL DEFAULT 0,
  completed     INTEGER NOT NULL DEFAULT 0,
  updated_at    TEXT NOT NULL,
  PRIMARY KEY(video_id, account_id)
);
```

**心跳式进度与防快进**：

1. 播放请求经**分片鉴权**：服务端按 Range 校验已发布状态与账号范围，签发短时效分片凭证；未发布/下架不可获取分片。
2. 客户端每 N 秒上报 `{watch_id, position_ms}`（N 为配置项）；服务端把上次上报位置到本次位置之间作为**连续区间**写入 `watch_intervals(valid=1)`。
3. 大跳转（|Δposition| > 阈值，阈值配置化）判定为快进：当前连续区间作废（`valid=0`），从新位置重新开始，不补计跳转跨度。
4. 累计有效观看 `valid_ms` 取所有 `valid=1` 区间并集（去重重叠），**≥90% 总时长**才置 `completed=1`；未达标显示未完成。
5. 进度绑定 `account_id`；重开视频恢复 `last_position_ms`；一次打开不计完成。
6. 视频状态机：`uploading/processing → draft → pending → published → offline`，`failed` 可从上传/处理进入并可重试；未 published 学生端不可访问，下架不删文件。

**前端**：`ed-entry` 上传卡（进度/取消/失败原因/重试）、`ed-deck` 播放器（原生 `<video>`）、`pill` 发布状态；不支持格式显示明确提示。

**API**：`GET /api/v2/analytics/class`、`GET /api/v2/analytics/knowledge`、`GET /api/v2/analytics/question`、`GET /api/v2/analytics/export`。

### 5.8 MOD-OPS｜运维与可观测（FND-007/008、NFR-004/010/011/012）

**核心表**：`health_snapshots`（五态探测结果）、`task_states`（异步任务状态与重试次数）、`config_diagnostics`（配置项存在性/范围校验，不存 Key 值）、`backup_records` 复用 `backups`。

**五态探测**：应用存活、DB 可读写、目录可写、索引就绪、模型配置状态；P07 只定契约，P10 联调验证。

**日志脱敏**：写日志前过滤密码、Key、令牌、`student_no`；用 `account_id` + `request_id` 关联；Key 只以引用名出现在 `ai_providers.key_ref`。
