## 2. "统一风格与色调"的落地口径（可执行，不是口号）

| 维度 | A 基线统一值 | 角色差异边界 |
|---|---|---|
| 底色 | `--bg:#f6f2ea` 暖纸白；`--surface:#fdfbf6` | 学生/教师完全相同 |
| 主文字 | `--text:#24201c` 墨黑；`--muted:#6f6659` | 完全相同 |
| 强调色 | `--accent:#b23a2b` 朱砂；`--accent-soft:#f3e3de` | 完全相同 |
| 状态色 | `--ok:#4a6b45`、`--warn:#9a6a1e`、`--danger:#a5352b`（本次补齐，避免状态徽章跳出色调） | 完全相同 |
| 字体 | 展示 `Playfair Display / Noto Serif SC`；正文 `Noto Serif SC` | 完全相同 |
| 导航 | 竖排"目次"书脊 + 顶眉刊头 | **仅导航条目与标签按角色变化**（7 项 / 10 项），版式与配色不变 |
