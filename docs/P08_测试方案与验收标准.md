## 1. P08 范围与完成条件

V1.3 P08 要求：形成单元、接口、集成、UI 自动化（按需）、异常场景、安全、AI 效果评测（按需）、独立审查安排和用户验收标准；测试覆盖核心业务流程和异常场景；完成条件是**每个核心功能有明确测试方法和预期结果**。

本文件交付：

1. 75 项 MUST 逐项测试方法、预期结果、执行阶段与当前状态（§3）。
2. 42 样本 / 8 入口 / 71 场景受控清单的治理框架与真实锁定状态（§4 + `docs/controls/`）。
3. 500 节点 / 1500 边图谱压测方法（§5）。
4. 换教材 golden set 定义（OPEN-14，§6）。
5. A 基线静态门禁检查项（§7）。
6. 独立审查计划与用户验收标准（§8/§9）。

**本阶段不做**：执行测试、启动服务、安装依赖、生成真实测试证据（P10/P11/P12/P13）；不替教师或用户做业务验收签字。
